# UpTrend 📈

UpTrend is a virtual stock trading and learning platform designed to help beginners learn stock market trading without financial risk.

## Features
- Virtual stock trading
- Real-time chart visualization
- Portfolio tracking
- Market replay mode
- Trading academy
- Learning modules
- Skill analytics
- Daily practice simulations

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Firebase
- Lightweight Charts
